# Sistema de Gestión de Cursos - CESDE (Python Flask)

Aplicación backend desarrollada en **Python** con **Flask** y **SQLite**, optimizada para Fedora Linux y equipada con una interfaz web de bienvenida inspirada en la identidad visual corporativa de **Comfama**.

---

## Instalación rápida en Fedora
```bash
sudo dnf install python3-flask python3-flask-sqlalchemy
```
O bien:
```bash
pip install --user -r requirements.txt
```

---

## Ejecución
```bash
python3 app.py
```
Abre en tu navegador **`http://127.0.0.1:5000/`** para ver el panel interactivo con todos los accesos directos a los endpoints y filtros de la API.
